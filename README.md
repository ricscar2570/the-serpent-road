## 🎮 Cos'è The Serpent Road?

**The Serpent Road** è un GDR completo che combina survival brutale, combattimento tattico letale, e mistero cosmico in un vasto deserto post-apocalittico. Le antiche **Rovine Celesti** punteggiano le dune, nascondendo tecnologia così avanzata da sembrare magia. E qualcosa di enorme dorme sotto la sabbia...

### ✨ Caratteristiche Principali

- **🏜️ Survival Significativo** - L'acqua è vita. 2 litri/giorno o muori in 3 giorni.
- **⚔️ Combattimento Letale** - 2-3 colpi ti uccidono. Tattica > numeri.
- **✨ "Magia" Tecnologica** - Artefatti Celesti: lame plasma, mantelli ombra, lampade eterne.
- **🐍 Mistero Ambiguo** - Chi è il Serpente? Dio? AI? Forza cosmica?
- **🎭 Politica Grigia** - Nessuna fazione "buona". Impero brutale, Corsari caotici, Osservatori elitisti.

### 🎲 Sistema di Gioco

```
2d6 + dado abilità (d4→d10) ≥ Difficoltà
```

- **8 Abilità** core (Combattimento, Furtività, Percezione, ecc.)
- **10 Background** che definiscono il passato del PG
- **5 Valori** personali per scelte morali difficili
- **Tocchi di Qualità** per risultati eccezionali
- **Morte reale** - il deserto non perdona
